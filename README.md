# English Adventure — Antonio y Alejandra

Juego web en un único archivo, pensado para Safari en iPhone 11 y listo para GitHub Pages.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub y sube `index.html` a la raíz.
2. En **Settings → Pages**, elige **Deploy from a branch**, selecciona `main` y `/ (root)` y guarda.
3. Abre la URL que GitHub Pages muestra en esa sección desde el iPhone.

No necesita servidor ni dependencias de instalación. La voz en inglés usa la síntesis de voz disponible en el navegador y requiere conexión para cargar la tipografía; el resto del juego funciona sin conexión.

## Reglas actuales
- 10 retos aleatorios por partida, con preguntas de vocabulario, colores y escucha.
- Antonio y Alejandra alternan turnos; un error pasa el turno.
- Cada acierto suma 10 puntos y abre un minijuego de estrellas de 60 segundos.
- Con 60 puntos de equipo se propone una recompensa familiar (helado o cartas).
